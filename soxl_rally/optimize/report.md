# SOXL 一分K「起漲點 (r3)」參數與規則 Walk-Forward 優化報告

> **聲明**：本目錄僅做歷史回測與參數穩健性研究，**不含任何下單、券商／交易所交易 API 或推播程式碼**，亦未修改 `live_rules/` 內任何檔案。所有時間皆為台北時間（UTC+8）。

## 1. 研究方法與資料切分

- **標的與資料**：`../backtest_month/bingx_1m_raw.csv`（BingX `NCSKSOXL2USD-USDT` 永續一分K，2026-09-28 10:25 – 2026-10-31 09:52 UTC+8，共 47,488 根；正式評估區間 **2026-10-01 09:30 – 2026-10-31 09:30 UTC+8**）。
- **引擎對齊驗證**（`verify_engine.py`）：`r3_engine.py` 在預設參數下與 `backtest_month/signals.csv`（19 筆，+11.95%）、`signals_allday.csv`（32 筆，+8.39%）及停利 1% 敏感度（+0.26%）逐筆時間、出場原因、報酬率完全一致（誤差 0.0000%）。
- **交易成本與出場假設**：沿用月回測——通知 K 收盤價進場、同一根 K 同時觸及停損與停利時**優先算停損**、來回手續費 **0.1%**、不計滑價。
- **Walk-Forward 切分**：
  1. **前後半月對稱切分（2 週訓練 / 2 週驗證，含反向交叉驗證）**
     - 前半（IS，15 天）：`2026-10-01 09:30` – `2026-10-16 09:30`（現行規則 9 筆，勝率 33.3%，平均 +0.23%，合計 +2.11%）
     - 後半（OOS，15 天）：`2026-10-16 09:30` – `2026-10-31 09:30`（現行規則 10 筆，勝率 50.0%，平均 +0.98%，合計 +9.84%）
     - 反向驗證：以後半選參數、回頭測前半，檢查是否只是單邊行情巧合。
  2. **逐週滾動 / 錨定 Walk-Forward（4 週：`W1` 10/01–10/08、`W2` 10/08–10/15、`W3` 10/15–10/22、`W4` 10/22–10/31）**
     - **Anchored（累積視窗）**：用 `W1..Wk` 挑平均每筆期望值最高者（要求訓練期至少 3 筆），測試 `W(k+1)`。
     - **Rolling-1W（單週滾動）**：只用前一週 `Wk` 挑參數，測試 `W(k+1)`。

## 3. 多參數網格與 Walk-Forward 驗證（`grid_is_oos.csv`、`rolling_wf.csv`）

我們對 `drop ∈ {2.0%, 2.5%, 3.0%}` × `band ∈ {0.75%, 1.0%, 1.5%, 2.0%}` × `band_side ∈ {both, above}` × `cool ∈ {30, 60}` × `tp ∈ {1.5%, 2.0%, 2.5%, 3.0%, 4.0%}` × `sl ∈ {swing30, l2_1pct, pct1.5}` × `max_bars ∈ {60, 120, 180}` 共 **2,160 組**做完整交集評估：

### 3.1 整體參數空間分布與 IS↔OOS 相關性

- **正期望值比例**：2,160 組中，全月平均每筆 > 0 的佔 **88.9%**（前半 IS > 0 佔 71.1%，後半 OOS > 0 佔 87.9%）。只要 `tp ≥ 2.5%` 且 `sl ≠ l2_1pct`，絕大多數鄰近參數都是正報酬，顯示核心邏輯並非單點奇蹟。
- **但 IS 與 OOS 排名相關性極低（甚至略負）**：
  - 全部 `n_is ≥ 5` 組合：IS 平均報酬與 OOS 平均報酬的 **Pearson = −0.036、Spearman = −0.033**。
  - 若固定 `band_side = both`（1,080 組）：**Pearson = +0.099、Spearman = +0.092**。
  - 意義：**在 15 天（約 5–12 筆交易）的小樣本上追求「訓練期第一名」，幾乎無法預測下一個 15 天的第一名**。

## 4. 結論與實務建議（不挑最漂亮組合，只留結構性結論）

1. **不要大改現行 `r3` 進場參數**：
   - `drop = 2.5%`、`l2_ma_buf = 1.5%`、`session = 美股 21:30–04:00 平日`、`cool = 30m` 都正好位於參數高原中央。
   - **不可拿掉的兩個濾網**：
     - `us_session`（台北 21:30–04:00 平日）：非美股時段 13 筆合計 −3.56%。
     - `L2 >= MA200 × 0.985`：若放寬為不限制，全月由 +11.94% 變為 −1.62%。
2. **出場端最重要的發現：期望值來自「不對稱盈虧比（TP ≥ 2.5%–3.0%，停損約 −1%）」，而非高勝率**：
   - 把停利縮到 `+1%`（或把停損貼到 `L2`）會讓單筆期望值從 `+0.63%` 跌到 `+0.01%~+0.28%`，因為 SOXL 一分 K 突破後常先回測 `B` 或 `L2` 附近才走出 3% 波段。
   - `swing30 × 0.999`（近 30 根最低價再減 0.1%）比 `max(L2, -1%)` 穩健得多。
   - `max_bars`（時間出場）從 120 分鐘縮短至 **60 分鐘** 在 IS 與 OOS 皆有小幅正面效果（全月 +11.94% → +13.04%），因為起漲點若 1 小時內還走不出 +3%，後續動能通常已經衰退。

   - **方案 B：排除「1–4 個 tick 假墊高」的平底（要求 `L2 >= L1 × 1.0005`，即至少墊高 5 bp / 0.05%）**
