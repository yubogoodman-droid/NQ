Tradovate 跟單台

主帳下一筆，其他帳自動跟。只連你自己的帳。

它只做一件事

這不是 prop firm，也不會幫你出金。你在 主帳 買或賣， 程式把同一筆複製到 跟單帳。 預設是「主帳成交了，跟單帳下市價單」。

主帳
你在 Tradovate / TradingView 下單的地方
LEAD
倉位：空倉
成交之後往下複製

這些按鈕是示範，不會連交易所。看懂之後再用下面的指令接真帳。

設定是什麼意思

寫在 copier.yaml

口數比例 qty_ratio

主帳買 2 口、比例 1.0 → 跟 2 口。比例 0.5 → 跟 1 口。也可以改 qty_fixed: 1 每次都跟固定口數。

契約對應 symbol_map

主帳打大台 NQ，跟單帳可以改打微型 MNQ。右邊那張示範帳就是這樣設的。

最多幾口 max_contracts

跟單帳這個契約的絕對倉位上限。到了就不再加倉，但平倉、反向減倉還是會做。

日虧鎖定 daily_loss_limit

該帳今天已實現虧超過金額就停跟，可選擇順便平掉。美東 18:00 換日後解鎖。

要接真帳時

先 demo + dry-run
Tradovate 開 API

Application Settings → API Access，權限不要設成 read-only。Demo 和 live 是不同環境。

填憑證，列出帳號

複製 copier.env.example → copier.env，填帳密。然後：

python3 examples/tradovate_copier.py list-accounts
指定主帳 / 跟單帳

複製 copier.example.yaml → copier.yaml，把印出來的帳號名稱填進 lead 與 followers。

開這個網頁看即時狀態

先乾跑，確認畫面出現「已複製」再拿掉 dry-run。Live 一定要加 --live。

python3 examples/tradovate_copier.py web --dry-run --poll 2
